# NetCoreEls
This project demonstrates how to implement structured logging in a .NET Core 9.0 Console application using Serilog, with logs being sent to an Elasticsearch instance. It also includes the setup of Elasticsearch and Kibana services via Docker containers to enable centralized log storage and real-time log visualization.

# Technologies Used
.NET Core 9.0 Console Application
Elasticsearch
Kibana
Docker & Docker Compose

# Features
Sending logs from a console application to Elasticsearch
Visualizing and analyzing logs in Kibana
Easy setup with Docker containers
